# Monster Hunter Portable 3rd HD Ver. — Traducción al Español

Proyecto de traducción al español de **Monster Hunter Portable 3rd HD Ver.** para Yakumo[https://github.com/TeamGDB/Yakumo]

> **Proyecto no oficial de fans.** Este repositorio no está afiliado, respaldado ni patrocinado por Capcom. Monster Hunter y sus marcas relacionadas pertenecen a sus respectivos propietarios.

## Estado

**Traducción principal completada.**

El objetivo del proyecto es ofrecer una versión jugable en español manteniendo, en la medida de lo posible, la intención y el contexto de los textos originales y adaptándolos a las limitaciones del juego.

## Cambios realizados

De forma general, el trabajo realizado incluye:

- Traducción al español de los textos trabajados dentro de la versión HD del juego.
- Revisión y sustitución de cadenas de texto en las distintas tablas procesadas durante el proyecto.
- Adaptación de textos de interfaz, mensajes y contenido jugable incluido en dichas tablas.
- Corrección de textos que requerían ajustes de longitud, formato o contexto para funcionar correctamente dentro del juego.
- Homogeneización de terminología para mantener una traducción más coherente entre distintas secciones.
- Revisión progresiva de las tablas traducidas hasta completar el conjunto tratado en el proyecto.
- Integración de los textos traducidos en la imagen de juego utilizada para las pruebas finales.

Para un resumen por versión, consulta [CHANGELOG.md](CHANGELOG.md).

## Distribución

Este repositorio **no incluye una ISO completa del juego ni archivos originales protegidos por copyright**.

La forma recomendada de distribuir la traducción es mediante un **parche** lang para que el usuario aplique sobre su propia copia legítima del juego. 
Coloca el archivo de parche final en la carpeta [`patches/`](patches/).
